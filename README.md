# TikiTiki 🎟️ 有票噴霧

支援拓元 tixCraft、KKTIX、ibon 與遠大 ticketplus 的 Chrome 購票輔助擴充功能，協助篩選區域、自動選票與填入購票資料。

## 安裝與使用

1. 下載或 clone 此專案。
2. 開啟 `chrome://extensions`，啟用「開發人員模式」。
3. 點「載入未封裝項目」，選擇本專案資料夾。
4. 點擴充功能圖示，設定各平台的購票偏好。

設定會自動儲存。更新程式後，請重新載入擴充功能，再重新整理設定頁與購票頁；修改拓元區域顯示規則後，也需重新整理選區頁。

## 支援功能

| 平台 | 主要功能 |
| --- | --- |
| 拓元 tixCraft | 區域顯示與隱藏關鍵字、自動選區、購票張數、驗證碼放大、自訂購票驗證字串 |
| KKTIX | 指定票種與優先順序、自動選票、隱藏身障票種、自動帶入資格碼 |
| ibon | 電腦配位選區、購票張數、不連位設定 |
| ticketplus | 加入票種或依票價選區、點擊「+」增加購票張數 |

購票頁的小工具提供時鐘、自動點擊開關與設定入口。

## 使用前留意

- **拓元**：自動點擊關鍵字留空代表不限區域，但仍會排除已隱藏的區域。設定頁與小工具開啟自動選區都會立即執行。票價關鍵字如 `2,800` 按 Enter 後會儲存為 `2800`。
- **KKTIX**：先在報名頁將票種加入自動點擊範圍，未加入時不會自動選票。顯示的票種上限不是剩餘庫存。修改選票規則會保留已選張數，清除後才套用新規則；已有張數的身障票種不會隱藏。
- **ibon**：目前僅支援 UTK02 電腦配位的選區與單一票種數量頁。自動選區需填入關鍵字；購票張數與不連位設定不受自動選區開關影響。
- 指定張數預設須剛好符合；拓元與 KKTIX 可允許不足時改選較少張。最大張數依網站提供的選項或上限決定。
- **ticketplus**：可在購票頁點開票區後按票種旁的「＋」加入清單（同 KKTIX），已加入時依加入順序選票；清單為空時改依票價加入順序選第一個符合的區域。逐次點擊「+」到指定張數，剩餘不足或無法加到指定張數時改選下一個。
- KKTIX、ibon 與 ticketplus 選票後，請自行確認並按「下一步」。
