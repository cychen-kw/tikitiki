# TikiTiki 🎟️ 有票噴霧

購票輔助 Chrome 擴充功能，支援拓元售票（tixCraft）與 KKTIX。

本專案 fork 自 [dsync5566/tixCraftSupport](https://github.com/dsync5566/tixCraftSupport)，沿用原作者的 GPLv3 授權，在此基礎上重寫並新增了不少功能。感謝原作者提供的基礎架構。

## 安裝

本專案未上架 Chrome Web Store，需手動安裝：

1. 下載或 clone 此專案
2. 開啟 `chrome://extensions`，右上角開啟「開發人員模式」
3. 點「載入未封裝項目」，選擇本專案的資料夾

## 功能

### 拓元 tixCraft

**節目 / 場次頁面**
- 可設定「自動跳過節目介紹頁，直接前往場次列表」
- 場次列表（`#gameList`）的每個場次名稱會自動加上超連結，直接連到購票頁面；尚未開賣、按鈕還沒出現時，會用場次代碼反推網址

**選區頁面**
- 自動隱藏「遮擋」「護網」「鐵網」「不完整」等標註不佳的區域
- 自動隱藏名稱含「身障」「身心障礙」「輪椅」的區域
- 自動隱藏已售完的區域（預設開啟）
- 「僅顯示這些區域」：輸入關鍵字（可多個，逐一新增/移除），只留下符合的區域，其餘隱藏
- **自動點擊**：輸入關鍵字（留空代表不限區域），符合條件時自動點進區域
  - 預設只考慮「熱賣中」或剩餘票數達到你設定張數的區域；勾選「允許點擊票數不足的區域」可以放寬這個限制
  - 符合條件的區域有多個時，依你選擇的規則排序：畫面排前面優先、排後面優先、依關鍵字輸入順序、票數最多者（同票或都熱賣中則隨機）、或純隨機
- 中文、英文頁面都支援（「熱賣中」/「Available」、「剩餘 N」/「N seat(s) remaining」都認得）

**選票頁面**
- 購票張數可選 1～4 張或最大張數；指定張數預設只選剛好符合的選項，允許票數不足時選不超過目標的最高可選張數
- 驗證碼圖片自動放大兩倍
- 自動勾選同意條款，並將游標移至驗證碼輸入框

**驗證頁面**
- 標題含「中信」「富邦」「玉山」字樣時，自動帶入對應銀行的信用卡卡號前六碼（僅供銀行別驗證，與實際刷卡卡號無關）
- 可在設定頁自訂字串，有值時優先填入；留空才使用銀行自動偵測
- 頁面上標紅的提示文字可以直接點擊，會自動清空並填入輸入框

**懸浮小工具**（節目、場次、選區、選票、驗證頁面右上角都有）
- 即時時鐘（含秒數）
- 「自動點擊」快捷開關，不用進設定頁就能隨時開關
- 顯示目前優先規則，修改設定後同步更新
- ⚙️ 按鈕直接開啟設定頁
- 可以縮小成只顯示時鐘，但無法關閉

### KKTIX

- 可開啟「隱藏身障票種」，隱藏名稱含「身障」「身心障礙」「輪椅」的整列票種並排除自動選票；預設關閉，取消勾選後恢復顯示
- 每個票種下方顯示票種上限與本票種已選張數，只依該票種上限與合法張數級距計算，不扣除其他票種張數；這不是庫存數量
- 報名頁右上角有懸浮小工具：即時時鐘（含秒數）、目前優先規則、「自動點擊」開關與 ⚙️ 開啟設定頁按鈕，可縮小；開關控制 KKTIX 自動選票，並同步設定頁儲存的開關狀態
- 設定頁可自訂資格碼；手動或自動選票後，資格碼欄位出現時自動帶入，保留大小寫與符號。留空停用，且不覆蓋已輸入或手動清空的欄位
- 報名頁面自動勾選「我已經閱讀並同意 服務條款 與 隱私權政策」
- 設定頁可獨立開啟「自動點擊」，選擇 1～4 張或最大張數（預設關閉、2 張）
- 報名頁每個票種旁的「＋」可加入自動點擊範圍，「✓」可移除；依活動儲存票種 ID，重新整理後保留
- KKTIX 設定頁的「已加入的票種」清單顯示 ID、節目名稱與票種，可個別移除或清空所有活動的範圍，立即儲存並同步報名頁；舊資料的名稱會在重新開啟對應報名頁後補上
- 範圍內可依畫面前面、後面、勾選順序、隨機或票種上限最多（同上限隨機）選擇一種票；未加入票種時不會自動選票
- 綠色「✓ 1、✓ 2…」標示加入範圍的順序；移除會重新編號，重新加入排最後。選擇「加入順序」時依編號優先
- 預設只選能剛好達到目標張數的票種；勾選「允許票數不足」時，選不超過目標的最高合法張數。五人團票不會因設定 2 張而被加到 5 張
- 逐次點擊網站原本的加號，已選張數計入目標；最大張數以網站上限為準。達到目標、加號停用或點擊後張數未增加時停止，票數不足時保留已選張數供確認
- 完成後不會因手動減票而自動補回；重新開啟自動選票、變更設定／範圍或重新整理後再執行。其他票種已有張數時暫停選票，避免混買
- 選票後自行確認並點擊「下一步」

選票邏輯檢查：`node tests/kktix.test.js`

## 設定頁

左鍵或右鍵點擴充功能圖示都可以打開設定頁（右鍵需選擇「選項」）。頁面依平台分成「拓元 tixCraft」「KKTIX」兩個分頁，各自用對應的主題色（藍/綠）。點左上角的 🎟️ 圖示有個小彩蛋。

所有設定變更後自動儲存，並顯示「設定已儲存」；關鍵字按 Enter 新增，移除或清空也會立即儲存。兩個平台皆依區域顯示、自動點擊、購票張數、驗證欄位排列。
