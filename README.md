# TikiTiki 🎟️ 有票噴霧

購票輔助 Chrome 擴充功能，支援拓元售票（tixCraft）與 KKTIX。

本專案 fork 自 [dsync5566/tixCraftSupport](https://github.com/dsync5566/tixCraftSupport)，沿用原作者的 GPLv3 授權，在此基礎上重寫並新增了不少功能。感謝原作者提供的基礎架構。

## 安裝

本專案未上架 Chrome Web Store，需手動安裝：

1. 下載或 clone 此專案
2. 開啟 `chrome://extensions`，右上角開啟「開發人員模式」
3. 點「載入未封裝項目」，選擇本專案的資料夾

## 功能

### 拓元 tixCraft

**節目 / 場次頁面**
- 可設定「自動跳過節目介紹頁，直接前往場次列表」
- 場次列表（`#gameList`）的每個場次名稱會自動加上超連結，直接連到購票頁面；尚未開賣、按鈕還沒出現時，會用場次代碼反推網址

**選區頁面**
- 自動隱藏「遮擋」「護網」「鐵網」「不完整」等標註不佳的區域
- 自動隱藏身障優惠區
- 自動隱藏已售完的區域（預設開啟）
- 「僅顯示這些區域」：輸入關鍵字（可多個，逐一新增/刪除），只留下符合的區域，其餘隱藏
- **自動點擊**：輸入關鍵字（留空代表不限區域），符合條件時自動點進區域
  - 預設只考慮「熱賣中」或剩餘票數達到你設定張數的區域；勾選「允許點擊票數不足的區域」可以放寬這個限制
  - 符合條件的區域有多個時，依你選擇的規則排序：畫面排前面優先、排後面優先、依關鍵字輸入順序、票數最多者（同票或都熱賣中則隨機）、或純隨機
- 中文、英文頁面都支援（「熱賣中」/「Available」、「剩餘 N」/「N seat(s) remaining」都認得）

**選票頁面**
- 自動選擇最大張數，或依設定選擇指定張數
- 驗證碼圖片自動放大兩倍
- 自動勾選同意條款，並將游標移至驗證碼輸入框

**驗證頁面**
- 標題含「中信」「富邦」「玉山」字樣時，自動帶入對應銀行的信用卡卡號前六碼（僅供銀行別驗證，與實際刷卡卡號無關）
- 可在設定頁自訂一組備用字串，銀行自動偵測失敗時使用
- 頁面上標紅的提示文字可以直接點擊，會自動清空並填入輸入框

**懸浮小工具**（節目、場次、選區、選票、驗證頁面右上角都有）
- 即時時鐘（含秒數）
- 「自動點擊」快捷開關，不用進設定頁就能隨時開關
- 可以縮小成只顯示時鐘，但無法關閉

### KKTIX

- 報名頁面自動勾選「我已經閱讀並同意 服務條款 與 隱私權政策」

## 設定頁

左鍵或右鍵點擴充功能圖示都可以打開設定頁（右鍵需選擇「選項」）。頁面依平台分成「拓元 tixCraft」「KKTIX」兩個分頁，各自用對應的主題色（藍/綠）。點左上角的 🎟️ 圖示有個小彩蛋。
